# Финальная привязка Colab к выбранной модели

Этот документ описывает выпуск после завершения обучения 14 октября в 16:00 МСК. Текущие ссылки в DLA_ASR_Demo.ipynb и resources.json относятся к прежнему проверенному e05c; они не являются доказательством приёмки ночной модели.

1. Дождаться actual train_exit обоих тренеров, закрытых резервов и завершения финального evaluator. Сохранить selection.json и complete.json. Выбор модели и декодера выполняется только по полным dev; test запускается после фиксации.
2. Проверить выбранные model-only/full checkpoint: SHA-256, все тензоры, optimizer/scheduler/RNG, восстановление и цепочку родителей. Сохранить измеренные полные test-clean/test-other отдельно от dev.
3. Заморозить исходники инференса в commit A и создать source.zip через git archive. Загрузить этот архив как новый ресурс, проверить анонимное скачивание и SHA-256. Существующие архивы сохраняются.
4. Создать новый resources.json B с URL/SHA выбранной модели, LM, примеров и фактическими inference_options. Обязательно сравнить model_sha256 с SHA модели из окончательного selection.json, а не только с resources[0].sha256. Настройки decoder/beam_width/lm_weight/word_bonus и SHA LM должны совпадать с зафиксированной dev-конфигурацией. Загрузить B, проверить анонимные байты и SHA.
5. В новом финальном notebook C заменить SOURCE_ARCHIVE_URL/SHA256 и RELEASE_MANIFEST_URL/SHA256. Git fallback: codex/hw1-asr-overnight-20261014. Проверить, что код инференса и зависимости C совпадают с A; разрешённые отличия выпуска — ссылки notebook, resources, отчёт и доказательства. Внешний manifest B заменяет встроенный resources.json из A до скачивания модели, поэтому циклической зависимости SHA source.zip нет.
6. Выполнить все 12 ячеек нового notebook в свежем Colab, где /content/DLA-ASR-2026 изначально отсутствует. Проверить набор с эталонами и без: точные исходные ID, TXT, метрики с эталонами и null без них. Сохранить выполненные notebooks и исходники; кроме DATASET_URL исходные ячейки должны совпадать с финальным master. Старый e05c/extension Colab не заменяет эту проверку.
7. Обновить FINAL_RESULTS.md, REPORT.md/PDF, resources.json и итоговые ссылки только из проверенного нового выпуска. Все страницы PDF визуально проверить. Собрать новый комплект с --source-ref codex/hw1-asr-overnight-20261014; source-ref обязан указывать на HEAD. Проверить SHA всех ресурсов, ZIP CRC/членов, восстановление Git bundle в точный commit и происхождение шаблона.

Если публикация GitHub недоступна, разрешённый пользователем вариант доставки — проверенные Git bundle и архив. Успех публикации и анонимного скачивания подтверждается отдельно. Правило курса о запрете LLM явно остаётся в отчёте.
