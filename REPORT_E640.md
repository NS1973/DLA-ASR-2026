# HW1 ASR — проверенный промежуточный результат

Состояние на 13 октября 2026 года, 18:00 МСК. Этот документ относится только к сохранённой модели e640. Дополнительное обучение на смеси clean/other продолжается до 20:40 МСК; его результаты сюда не включены. Прежний комплект baseline сохранён отдельно. Окончательная сдача состоится после проверки выбранного кандидата.

## Модель, данные и обучение

Собственная DeepSpeech2-подобная CTC-модель содержит 24 471 453 параметра: две свёртки, пять двунаправленных GRU по 512 единиц на направление и линейный выход. Вход — mono 16 кГц, 80 log-Mel полос, окно 25 мс, шаг 10 мс. Алфавит: 26 букв, пробел, апостроф, CTC blank. Длины после свёрток вычисляются явно; CTC loss считается в FP32 при BF16 forward.

До фиксации e640 использовались только train-clean-100 и train-clean-360, суммарно 464,196 часа. Dev-clean и dev-other служили для выбора модели и декодера. Test не использовался для обучения и настройки. Собственная цепочка родителей начинается с обучения staging с нуля и продолжается этапами на clean; внешний акустический checkpoint не применялся. Полная ранняя цепочка описана в REPRODUCTION.md и сохранена в initializations.zip.

Выбран lr_candidate_extension1326_effective_v2, последний checkpoint: step 34937, epoch 33, batch_index 749. Его родитель — собственная модель d919, уже оценённая в первой кампании. На новом этапе создан новый optimizer/scheduler: AdamW, batch 128, LR 2e-5, weight decay 1e-4, warmup 100 шагов, cosine с горизонтом 40 эпох, clipping 5, seed 1, data_epoch_offset 120. Обучение штатно завершено по календарному cutoff 15:25 МСК. valid_limit=256 относится только к промежуточному мониторингу; итоговый выбор выполнен по полным dev-наборам.

Профиль effective_v2 содержит четыре аудиоаугментации: громкость с плавной огибающей, шум, скорость и слабую контролируемую реверберацию. Исходные и преобразованные WAV/спектрограммы сохранены отдельно. Legacy-режим и его результаты сохранены для сравнения.

## Выбор до итогового test

Рассмотрены best и last десяти завершённых запусков; одинаковые model-only SHA учитывались один раз. По утверждённому пользователем правилу выбирался минимальный корпусный greedy WER полного dev-other среди моделей с полным dev-clean WER не выше 20%; при равенстве — dev-clean и имя. Для выбранной модели greedy даёт 14,31014% на dev-clean и 39,21253% на dev-other.

Затем на обоих полных dev-наборах проверены 13 настроек: greedy; собственный prefix beam ширины 10/20/50; те же beam с LM weights 0.1/0.2/0.3, word bonus 1 и token_topk 8. Выбран beam10 + LM 0.2 по dev-other с ограничением clean. Модель и декодер зафиксированы до запуска test. Настройки после test не менялись.

## Ограничения и продолжающееся обучение

Порог test-clean WER ≤20% достигнут; test-other ≤30% не достигнут. Эти значения — уровни таблицы качества курса, а не самостоятельная гарантия итоговой оценки. Публикация приватного исходного репозитория и анонимный clone пока не пройдены; готовый Git bundle предусмотрен как согласованный пользователем резервный способ передачи.

Для следующих кандидатов добавлены 100,1166 часа train-other-500: первые полные главы в порядке официального архива, не случайная выборка. Полный исходный архив 500 часов не скачан и не проверен целиком. Все отобранные записи, тексты, SHA, CTC-длины и отсутствие пересечения с clean/dev/test проверены. На одной GPU обучается смесь всех 464,196 часов clean и этого other-поднабора с повторениями; вторая GPU остаётся clean-контролем. Эти эксперименты будут оценены отдельно после 20:40 по полному dev-other с ограничением dev-clean ≤20%, затем по замороженным настройкам на test.

Правила курса запрещают использование LLM. Работа подготовлена с AI-помощью; техническая воспроизводимость не подтверждает соответствие этому правилу. Ограничение раскрыто явно.
